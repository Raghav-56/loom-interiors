# Research and source choice

Research took place before implementation on 14 October 2026.

[INFRA INTERIORS](https://github.com/arshc0der/Interior_Design_Website) is an HTML, CSS, and JavaScript alternative. Its [MIT license](https://github.com/arshc0der/Interior_Design_Website/blob/main/LICENSE) permits code reuse under its license conditions. It was considered as a quick frontend starting point.

[Debora Interiors' portfolio](https://deborainteriors.com/interior-design-ideas/) illustrates image-led room browsing and a consultation entry point. It was a content-structure reference only.

The user then confirmed that the existing Loom Interiors archive came from the friend and that the attached report describes that project. The supplied source was therefore the better foundation: it already matches the report's name, React stack, four style directions, camera preview, and draggable chat.

No external template code or imagery was copied. The project keeps the supplied implementation and repairs incomplete behavior. Source ownership and image reuse remain with their respective creators.
